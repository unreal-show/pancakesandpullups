# Pancakes & Pull-ups

Free training plans, meal plans and recipes by Marcus Brooks (UNREAL). Static site on GitHub Pages at https://www.pancakesandpullups.com

- index.html, training.html, meal-plans.html, about.html, recipe-<id>.html (one per recipe, with Recipe structured data), 404.html
- app.js holds the recipe data (ING = per-100 g USDA values, RECIPES = gram weights) and the plan builders (minified).
- sitemap.xml + robots.txt
